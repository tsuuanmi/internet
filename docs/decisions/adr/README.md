# Accepted Architecture Decision Records

This directory contains accepted ADRs for current production behavior.

- ADR-0001 through ADR-0008 are accepted decision history.
- Accepted ADRs are durable; material replacement should use a successor record.
- Proposed decisions do not belong here.
